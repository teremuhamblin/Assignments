# bmeg400E-Genome424

- 》》 **Cours avancé de génie biomédical intitulé Topics in Biomedical**.

- 》》 **"Engineering – Genome Informatics"**
   - **Informatique du génome, désormais renuméroté de façon permanente sous le code** ***BMEG424***.

### Aperçu du cours

#### • Objectif :
- *Bonnes pratiques pour le traitement de vastes ensembles de données génomiques, analyses statistiques, pièges courants et interprétation des données de séquençage biologique*.

#### • Format :
- *Combine des cours magistraux avec des exercices pratiques sur ordinateur et est parfois donné conjointement avec une version de niveau supérieur (BMEG 524 / BMEG 591E)*.

#### • Préalables :
- *L'un des cours suivants : BMEG 310, CPSC 455 ou MICB 405 (les étudiants qui ne sont pas inscrits en génie biomédical doivent généralement contacter l'enseignant et s'inscrire sur une liste d'attente)*.

#### • Évaluation :
- *Non admissible à la mention Crédit/D/Échec (Cr/D/F) en raison des règlements du Bureau canadien d'accréditation des programmes d'ingénierie (BCAPI)*.

#### • Changement de numéro de cours :
- *Officiellement mis à jour et renuméroté dans le programme de l'UBC sous le code BMEG 424 (Genome Informatics)*.
