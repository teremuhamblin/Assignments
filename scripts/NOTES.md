### Notes d'utilisation rapide

### • Permissions :
- 》》》 *Rendez vos scripts exécutables avant de les lancer* :

```bash
chmod +x scripts/*.sh scripts/*.R
```
>Utilisez le code avec précaution.

### • Convention
- 》》》 **nommage FASTQ** :
*Les scripts 02 et 03* supposent que vos fichiers bruts se terminent par *_R1.fastq.gz et _R2.fastq.gz* (**format standard Illumina**).

- 》》》 Si vos fichiers se terminent par *_1.fastq.gz ou .fq.gz*, il suffira d'ajuster ce suffixe.
